# Laya Moderator

[English version](README.md)

Self-hosted Telegram-бот, который проверяет каждое сообщение в группе AI-классификатором. Спам, рекламу и оскорбления он удаляет, а автора ограничивает по нарастающей лестнице наказаний.

> **Статус:** проектирование. Архитектура описана, работающего кода пока нет.

## Возможности

- **AI-модерация.** Бот проверяет текст, подписи к медиа и отредактированные сообщения. По умолчанию работает [Laya](https://huggingface.co/convaiinnovations/laya) локально на CPU. Вместо неё можно подключить облачный API [Jev](https://docs.typesafe.ai).
- **Две зоны уверенности.** Явные нарушения бот обрабатывает сам. Сомнительные сообщения уходят администратору с кнопками «Наказать» и «Пропустить».
- **Сначала режим наблюдения.** Новый чат стартует без действий: бот только показывает, что бы он сделал. Автомодерацию вы включаете, когда убедитесь, что ему можно доверять.
- **Настраиваемая лестница наказаний.** По умолчанию 1 час → 24 часа → навсегда. Каждое нарушение сгорает через 30 дней. Участник остаётся в чате, у него просто отбирается право писать.
- **Апелляции.** Ограниченный участник нажимает «Это ошибка». Администратор получает цитату удалённого сообщения и кнопки «Снять ограничение» и «Отклонить».
- **Свои тексты уведомлений.** Можно задать свой текст с полным форматированием и плейсхолдерами `{user}`, `{reason}`, `{duration}`, `{strike}`.
- **Интерфейс в одном сообщении.** Инлайн-меню меняется на месте при переходах между экранами, кнопки цветные (Bot API 9.4+).
- **Русский и английский.** Язык интерфейса администратора и язык каждого чата выбираются отдельно.

## Быстрый старт

Нужен Docker с Compose и около 3 ГБ RAM, если запускать локальную модель Laya.

1. Создайте бота в [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Настройте и запустите:

   ```bash
   git clone https://github.com/Romay777/laya-telegram-mod.git
   cd laya-telegram-mod
   cp .env.example .env    # укажите BOT_TOKEN и POSTGRES_PASSWORD
   docker compose up -d --build
   ```

3. Откройте бота в Telegram, нажмите **Start**, выберите язык и нажмите **Добавить в чат**. Telegram предложит выбрать супергруппу и сразу выдаст боту нужные права: удаление сообщений и ограничение участников.

### Jev вместо Laya или вместе с ней

Укажите `JEV_API_KEY` в `.env`. По умолчанию `JEV_BASE_URL` указывает на TypeSafe. Для OpenRouter поставьте `https://openrouter.ai/api/v1`. После этого бэкенд можно выбрать для каждого чата в настройках бота. Чтобы работать только через Jev без локальной модели, удалите `COMPOSE_PROFILES=laya` из `.env`.

Если для чата включён Jev, тексты его сообщений отправляются стороннему API.
